# AKLT Quantum Spin Chain

Numerical study of the spin-1 AKLT model, investigating its ground states, energy spectrum, and quantum correlations.

**Methods:**
- Exact diagonalisation
- Density Matrix Renormalisation Group (DMRG)
- Time-Evolving Block Decimation (TEBD)

Implemented in Python using NumPy, SciPy, TeNPy, and Quimb.
